# Smart Education Training - Écrans Interactifs

## 📱 Vue d'ensemble

Plateforme d'écrans interactifs pour l'éducation intelligente, conçue pour offrir une expérience d'apprentissage interactive et engageante.

## 🎯 Fonctionnalités

### Écrans Principaux

1. **Accueil** 🏠
   - Cartes interactives de bienvenue
   - Navigation rapide vers les différentes sections
   - Interface intuitive et responsive

2. **Leçons** 📚
   - Modules d'apprentissage par matière (Mathématiques, Sciences, Langues, Histoire)
   - Barre de progression pour chaque leçon
   - Design visuel attractif avec animations

3. **Exercices** ✏️
   - Exercices pratiques avec différents niveaux de difficulté
   - Classification: Facile, Moyen, Difficile
   - Interface claire pour démarrer les exercices

4. **Quiz** 🎯
   - Quiz interactifs avec questions à choix multiples
   - Navigation entre les questions
   - Système de sélection visuel

5. **Ressources** 📖
   - Accès aux documents PDF
   - Vidéos éducatives
   - Contenus audio
   - Liens utiles

## 🚀 Installation et Utilisation

### Démarrage Rapide

1. **Cloner le repository**
   ```bash
   git clone https://github.com/ALIDENGO/SMART-EDUCATION-TRAINING.git
   cd SMART-EDUCATION-TRAINING
   ```

2. **Ouvrir l'application**
   - Ouvrez simplement `index.html` dans votre navigateur web
   - Aucune installation de dépendances requise
   - Fonctionne sur tous les navigateurs modernes

### Pour les Écrans Tactiles

L'application est optimisée pour:
- Écrans tactiles interactifs
- Tablettes
- Smartphones
- Ordinateurs de bureau

## 🎨 Fonctionnalités Interactives

### Système de Navigation
- **Navigation par boutons**: Cliquez sur les boutons de navigation pour changer d'écran
- **Navigation par clavier**: Utilisez les touches 1-5 pour naviguer rapidement
- **Navigation tactile**: Support complet du touch pour écrans tactiles

### Feedback Visuel
- Animations fluides lors des transitions
- Effet de survol sur les éléments interactifs
- Feedback tactile visuel
- Notifications pour les actions utilisateur

### Responsive Design
- Adapté automatiquement à toutes les tailles d'écran
- Grille flexible pour les cartes et contenus
- Menu de navigation scrollable sur mobile

## 🔧 Personnalisation

### Couleurs
Les couleurs principales peuvent être modifiées dans `styles/main.css`:

```css
:root {
    --primary-color: #4A90E2;      /* Bleu principal */
    --secondary-color: #50C878;     /* Vert secondaire */
    --accent-color: #F5A623;        /* Orange accent */
    --danger-color: #E74C3C;        /* Rouge danger */
}
```

### Contenu
Le contenu des écrans peut être modifié directement dans `index.html`:
- Titres et descriptions
- Images et icônes
- Texte des questions et exercices

## 💡 Utilisation

### Navigation entre les Écrans

**Méthode 1: Boutons de Navigation**
- Cliquez sur les boutons en haut de l'écran (Accueil, Leçons, Exercices, Quiz, Ressources)

**Méthode 2: Raccourcis Clavier**
- Touche `1`: Accueil
- Touche `2`: Leçons
- Touche `3`: Exercices
- Touche `4`: Quiz
- Touche `5`: Ressources

**Méthode 3: Cartes Interactives**
- Cliquez sur les cartes de l'écran d'accueil pour accéder directement aux sections

### Interagir avec le Quiz
- Cliquez sur une option pour la sélectionner
- Utilisez les boutons "Précédent" et "Suivant" pour naviguer
- Utilisez les flèches ← → du clavier pour naviguer rapidement
