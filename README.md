# SMART EDUCATION TRAINING - ÉCRANS INTERACTIFS 📚

## 🎯 Description

Plateforme éducative moderne avec écrans interactifs pour l'apprentissage intelligent. Cette application web offre une expérience d'apprentissage interactive, intuitive et accessible sur tous les appareils.

## ✨ Fonctionnalités Principales

- 🏠 **Écran d'Accueil**: Interface de bienvenue avec accès rapide aux différentes sections
- 📚 **Leçons Interactives**: Modules d'apprentissage avec suivi de progression (Mathématiques, Sciences, Langues, Histoire)
- ✏️ **Exercices Pratiques**: Exercices avec différents niveaux de difficulté (Facile, Moyen, Difficile)
- 🎯 **Quiz**: Quiz interactifs avec questions à choix multiples
- 📖 **Ressources**: Accès aux documents, vidéos, audio et liens utiles
- 📱 **Responsive**: Compatible avec tous les appareils (ordinateurs, tablettes, smartphones, écrans tactiles)
- ⌨️ **Navigation Clavier**: Raccourcis clavier pour une navigation rapide
- 👆 **Feedback Tactile**: Retour visuel pour toutes les interactions

## 🚀 Démarrage Rapide

### Option 1: Ouvrir directement dans le navigateur
1. Clonez le repository:
   ```bash
   git clone https://github.com/ALIDENGO/SMART-EDUCATION-TRAINING.git
   ```
2. Ouvrez `index.html` dans votre navigateur web

### Option 2: Utiliser un serveur local
```bash
# Avec Python 3
python -m http.server 8000

# Avec Node.js
npx http-server

# Puis ouvrir http://localhost:8000 dans votre navigateur
```

## 🎮 Utilisation

### Navigation

**Boutons de Navigation**: Cliquez sur les icônes en haut de l'écran
- 🏠 Accueil
- 📚 Leçons
- ✏️ Exercices
- 🎯 Quiz
- 📖 Ressources

**Raccourcis Clavier**:
- `1` - Accueil
- `2` - Leçons
- `3` - Exercices
- `4` - Quiz
- `5` - Ressources

**Navigation Quiz**:
- `←` Flèche gauche - Question précédente
- `→` Flèche droite - Question suivante

Les couleurs principales peuvent être modifiées dans `styles/main.css`:

```css
:root {
    --primary-color: #4A90E2;      /* Bleu principal */
    --secondary-color: #50C878;     /* Vert */
    --accent-color: #F5A623;        /* Orange */
    --danger-color: #E74C3C;        /* Rouge */
}
```
